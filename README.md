# ImageMimicArt

手元の画像をローカル LLM (ビジョン対応) に読ませて説明プロンプトを作り、エンハンサーで盛ってから、ComfyUI で似た絵を生成する PySide6 製のアプリです。

```
元画像 ─ 読み取り ─→ 説明プロンプト (photo.txt) ─ エンハンサー ─→ 盛ったプロンプト ─ ComfyUI ─→ 生成画像
```

詳しい決まりごとは [docs/spec.md](docs/spec.md) にあります。画面と操作は J-Rate の `docs\ui-standard.md`、生成は `docs\generation-standard.md` に合わせています (生成まわりは PromptWordCrafter を引き継いでいます)。

## セットアップと起動

```powershell
pip install -r requirements.txt
```

`run_app.bat` をダブルクリックするか、このフォルダで `python main.py` を実行します。フォルダや画像のパスを引数に渡すと、そこを開きます。すでに起動しているときは、起動中のウィンドウを手前に出します。

初めて起動したときは、PromptWordCrafter の設定 (LLM のサーバーURL とモデル、エンハンサー、生成の設定) を引き継ぎます。

## はじめに設定するもの

1. **読み取りの設定** (ツールバー): サーバーURL (LM Studio などの OpenAI 互換 API) と、**ビジョン対応の**読み取り用モデル (qwen2.5-vl、gemma3 など) を選びます。「モデル取得」で一覧から選べます。
2. **生成の設定** (ツールバー): ComfyUI の接続先、ワークフロー (「Export (API)」で保存した JSON)、**出力フォルダ**を決めます。

## 使い方

- 左のツリー・Ctrl+O・ドロップでフォルダを開き、下のサムネール一覧や ← → で画像を選びます。
- **読み取る** (Ctrl+R): 表示中の画像を LLM に読ませ、右の枠に説明プロンプトを出して `photo.txt` に保存します。欄は直接直せて、Ctrl+S で保存します。
- **盛る**: 説明プロンプトをエンハンサーで盛って、下の欄に出します (ファイルには書きません)。
- **生成する**: 表示中 (複数選択中は選択中) の画像から生成します。右クリックの「一覧の画像をまとめて生成する」で一覧すべてから生成できます。説明プロンプトがまだない画像は、ジョブの中で読み取ってから生成します。
- 出来た画像は `出力フォルダ\(元画像のフォルダ名)\(元の名前)_mimic.png` に保存され、右の枠の下に並びます。クリックすると中央で元画像と並べて見られます (Esc で戻る)。
- ワークフローに「Load Image」ノードがあれば元画像も送ります (i2i・ControlNet など)。なければプロンプトだけで生成します。

## 主なキー

| キー | 動き |
|---|---|
| ← → ↑ ↓ / ホイール | 前へ / 次へ |
| Home / End | 先頭 / 末尾 |
| Del | ごみ箱へ削除 (元画像のみ。`.txt` は残す) |
| Ctrl / Shift + クリック | 複数選択 (Ctrl+D で解除) |
| Ctrl + ホイール | 拡大・縮小 (グリッドではタイルの大きさ) |
| Ctrl+R / Ctrl+S | 読み取る / 説明プロンプトを保存 |
| Ctrl+O / Ctrl+G / Ctrl+J | フォルダを開く / グリッド一覧 / 生成ジョブ |
| Esc | 元画像と並べるのをやめる・説明の欄から一覧に戻る |

説明プロンプトの欄など、文字を入力する欄にいるときは、矢印キーはその欄に効きます。

## 設定の保存先

`%APPDATA%\ImageMimicArt\` (生成の記録・ジョブ・プリセット・画面の設定)。
