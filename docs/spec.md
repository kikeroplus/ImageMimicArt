# ImageMimicArt 仕様

手元の画像をローカル LLM に読ませて説明プロンプトを作り、エンハンサーで盛ってから ComfyUI で画像を生成するアプリ。
「参考画像に似た絵を、プロンプト経由で作り直す」ためのもの。

- 共通の決まり: `J-Rate\docs\ui-standard.md` (画面・一覧の操作)、`J-Rate\docs\generation-standard.md` (生成)。この文書に書いていないことは両文書と J-Rate の動きに合わせる。
- 生成と読み取りの部品は PromptWordCrafter と共通の `GenCommon\gencommon` を使う。登録 (接続先・ワークフロー・ベースプロンプト・エンハンサー・読み取りプリセット・LLM の接続) は J-Rate・PromptWordCrafter と共有する (generation-standard 11 章)。読み取りの決まりは generation-standard 6 章「読み取り」に移した。この文書には ImageMimicArt だけのことを書く。
- 作り: Python + PySide6 (PromptWordCrafter と同じ)。2 重に起動しない。

---

## 1. 流れ

```
元画像 ─(1) 読み取り─→ 説明プロンプト (photo.txt) ─(2) エンハンサー─→ 盛ったプロンプト ─(3) ComfyUI─→ 生成画像
```

| 段 | 中身 | 使うもの |
|---|---|---|
| (1) 読み取り | 画像を見せて、説明プロンプトを書かせる | ビジョン対応の LLM + 読み取りプリセット |
| (2) エンハンサー | 説明プロンプトを生成 AI 向けに盛る (「なし」も可) | LLM + エンハンサー (PromptWordCrafter と同じ) |
| (3) 生成 | 盛ったプロンプト (+ ベースプロンプト) で生成 | ComfyUI + ワークフロー |

操作は 2 通りで、どちらもできる。

- **手で確かめながら**: 画像を選ぶ →「読み取る」→ 説明プロンプトを確認・手直しして保存 →「生成する」。
- **まとめて自動で**: 画像を選んで (または一覧すべて)「まとめて生成する」→ 読み取りから生成までジョブの中で進む。

## 2. 画面

ui-standard の 1〜5・7・9〜11・13〜16 章を採用する。**評価 (6 章) と評価でのコピー・移動 (8 章) は入れない** (評価は J-Rate で行う)。

| 場所 | 内容 |
|---|---|
| 上 | ツールバー: フォルダを開く \| 並び順・選択解除・グリッド一覧 \| 読み取る・生成する・生成ジョブ (n)・生成の設定 \| 読み取りの設定 |
| 左 | フォルダツリー |
| 中央 | 元画像を大きく表示 |
| 中央の下 | 元画像のサムネール一覧 (横 1 列) |
| 右 | プロンプトの枠 (下記) |
| 右の下 | この元画像から生成した結果のサムネール (新しい順) |
| 下 | ステータスバー |

- 一覧の対象は画像だけ (png / jpg / jpeg / jpe / webp / bmp。動画は出さない)。出力フォルダの生成画像も、そのフォルダを開けば普通に一覧できる。
- サムネールには印を付ける: 読み取り済み (`photo.txt` がある) は左上に「txt」、生成結果があれば右上にその数。
- 削除 (Del) は元画像と `photo.txt` を一緒にごみ箱へ送る (ui-standard 8 章「説明プロンプトの .txt」。`photo.jpg` など同じ名前の別の画像が残るときは `.txt` を残す)。
- **説明だけ残っている .txt** (同じ名前の画像がない `.txt`): フォルダを開いたときに数え、あればステータスバーで知らせ、右下の枚数の横に「説明だけの .txt N 個」と出す。ほかのアプリで画像だけを消して `.txt` が残ったものも数に入れる。
  右クリックの「説明だけ残っている .txt を整理 (N 個)...」で一覧の窓を開く (開くときに数え直す)。左に名前、右に中身・大きさ・更新日時を出す。このアプリと関係ないテキストも同じように見えるので、**最初はどれもチェックせず**、チェックしたものだけをごみ箱へ送る (ネットワーク上なら、完全に消えることを確かめてから)。
- **キーの例外**: キーはウインドウ全体で受けるが (ui-standard 13 章)、説明プロンプトなど文字を入力する欄にいるときはその欄に効く (矢印でカーソルが動く)。Esc で一覧に戻り、また矢印で画像を移動できる。生成結果のサムネールにいるときは、← → で生成結果を切り替える。
- 右の下の生成結果をクリックすると、中央を左右 2 つに分けて **元画像と生成結果を並べて見せる**。Esc か同じものをもう一度クリックで元に戻す。← → で生成結果を切り替える。ダブルクリック / Enter は関連付けアプリで開く。右クリックで「開く / 生成時の設定... / エクスプローラーで開く / ファイルを削除 (ごみ箱へ)」。

### プロンプトの枠 (右)

上から順に並べる。

1. **説明プロンプト** — `photo.txt` の中身を出す。直接直せて、Ctrl+S で保存する。保存していないまま別の画像に移る / 閉じるときは、保存するか聞く (PromptWordCrafter と同じ)。まだ読み取っていない画像では「まだ読み取っていません (読み取る: Ctrl+R)」と出す。
2. 読み取りプリセットの選択と「読み取る」(Ctrl+R)。すでに `photo.txt` があるときは「読み直す」になり、上書きしてよいか確認する。読み取り中は押せない。終わったら欄に入れて保存する。
3. **エンハンサー** の選択と「盛る」。結果は下の欄に出すだけで、ファイルには書かない (見るため。生成のときはジョブの中で改めて盛る)。
4. **盛ったプロンプト** — 読み取り専用。コピーアイコンあり。

## 3. 読み取り (1)

- 接続先は LM Studio などの OpenAI 互換 API (`/v1/chat/completions`)。画像は `image_url` に `data:image/jpeg;base64,...` で渡す。
- 送る前に縮める: 長い辺を 1024px (設定で変更可) にし、JPEG で送る。元より大きくはしない。透過は白で埋める。
- **読み取りプリセット**: 名前・指示文 (system)・送る文 (user)・temperature。最大 20 個。登録・並べ替えはエンハンサーと同じ作り (その場で保存)。初めて使うときは例を入れておく (自然文の詳しい説明 / タグ)。
- モデルは「読み取り用」と「エンハンサー用」を別々に選ぶ (同じでもよい)。「モデル取得」「接続テスト」あり。読み取り用にビジョン非対応のモデルを選んでいて画像を受け付けなかったときは、その旨を日本語で伝える。
- 返事の全体を囲むコードブロック・引用符・`<think>...</think>` は取り除く (エンハンサーと同じ)。

### 説明プロンプトのファイル

- 元画像と同じフォルダに **拡張子を除いた名前の `.txt`** (`photo.png` → `photo.txt`) を UTF-8 で書く。学習用キャプションと同じ慣習。
- `photo.png` と `photo.jpg` が並んでいると同じ `.txt` を使うことになる。読み取るときにこの重なりがあれば、ステータスバーで知らせる。
- 読み込むときは PromptWordCrafter と同じ順で文字コードを判定する。
- `photo.txt` があれば読み取り済みとみなし、自動では読み直さない。

## 4. 生成 (2)(3)

generation-standard に従う (セット・プリセット・ジョブ・同時 2 件・まとめて生成・続きから始める・一時停止・記録・パラメーターのコピー)。違う点だけを書く。

### 生成の画面

- 「プロンプト」の欄は **説明プロンプトを見せる欄** になる。
  - 1 枚のとき: 説明プロンプトの枠と同じ中身 (保存前の編集も含む)。生成の画面では書き換えない (直すのは右の枠で)。
  - まとめてのとき: 「N 枚 (読み取り済み a 枚 / 未読み取り b 枚)」と出す。
- 「読み取りプリセット」を置く。未読み取りの画像はこれで読み取る。「読み取り済みでも読み直す」のチェック (既定はオフ。オンなら `photo.txt` を上書き)。前回の値として覚える (生成を始めたときだけ)。
- 「エンハンサー」(なし / 登録済み) は PromptWordCrafter と同じ。
- プロンプトのプリセットは使わない (プロンプトは画像から作るため)。セットの中身は接続先・ワークフロー・長さ・読み取り (読み取りプリセットの名前と「読み直す」)・エンハンサー (名前) になる (generation-standard 2 章)。
- 1 枚で未読み取りなら、その場で読み取らずにジョブの中で読み取る (生成の画面は待たせない)。

### 元画像を ComfyUI に渡すか

- **ワークフロー次第**。`LoadImage` があれば元画像を送って入れる (generation-standard 5 章の J-Rate と同じ: 英数字の一時的な名前で `/upload/image`)。なければ渡さない (t2i)。
- 生成の画面のワークフローの下に「元画像も渡します (LoadImage あり)」/「プロンプトだけで生成します」と出す。
- プロンプトを入れる場所の扱いは PromptWordCrafter と同じ (`{prompt}` の目印 → 自動判定。使われる場所がなければ登録・生成させない)。

### ジョブの中の順番

1. **読み取り** (状態「読み取っています...」) — 未読み取り、または「読み直す」のとき。結果は `photo.txt` に書く。
   - 同じ画像の複数のジョブ (回数 2 以上) は、最初の 1 件だけが読み取り、残りはそれを待って同じ説明を使う。
2. **盛る** (状態「AI で盛っています...」) — エンハンサーを選んだとき。ジョブごとに盛るので、回数を増やすと毎回違う盛り方になる。
3. **ComfyUI** — 盛ったプロンプト + 改行 + ベースプロンプト (画像用) を送る。

- どの段で失敗してもジョブの失敗にする (読み取れないまま、盛れないまま送らない)。どの段でもキャンセルが効く。
- 読み取った説明と盛った本文はジョブに残す。続きから始めるときに、済んだ段はやり直さない。
- 一時停止は ComfyUI に頼む手前で止める (読み取り・盛りが済んだものは、その結果を持ったまま待機に戻す)。

### 出力

- 保存先は **設定の出力フォルダ** に、親フォルダ名と元画像のフォルダ名をつなげた名前で分けて置く:
  `(出力フォルダ)\(親フォルダ名)_(元画像のフォルダ名)\(元の名前)_mimic.png`
  (例: `\\RAVEN\SharBox\PhotoImage\grok-image\all\photo.png` → `出力フォルダ\grok-image_all\photo_mimic.png`。
  別の場所の同じ名前のフォルダが混ざらないように親の名前も付ける。名前のない段 (ドライブ・共有の直下) は `D`・`RAVEN_SharBox` のような名前で代える。)
  (動画のワークフローなら `_mimic.mp4`。同じ名前があれば ` (2)` などを付けて上書きしない。)
- 出力フォルダは「生成の設定」で決める (ワークフローと同じく、決まっていなければ最初の生成で「生成の設定」を開く。空のままでは OK を押せない)。
- 1 件だけの生成なら、終わったら右の下の生成結果に加えて、元画像と並べて見せる (オプション、既定はオン)。
- ツールバーの「最新の結果と並べる」(既定はオン、`compare_newest.txt`) がオンなら、画像を表示したとき、いちばん新しい生成結果を元画像の横に並べる。生成結果がなければ元画像だけ。Esc でその画像だけやめ、次の画像ではまた並べる。

### 記録

- generation-standard の項目に加えて、元画像のパス・読み取りプリセット名・説明プロンプト (送った時点の写し)・エンハンサー名・盛った本文を残す。盛った本文はファイルにせず、記録にだけ残す。
- 元画像と生成結果は **記録で結び付ける** (出力が別フォルダなので)。記録がないものは、出力フォルダの `(親フォルダ名)_(元画像のフォルダ名)\(元の名前)_mimic*` を拾う。
- 「旧」の印: 今の `photo.txt` と、記録の説明プロンプトが違えば付ける。
- 「この設定で生成する...」: 接続先・ワークフロー・長さ・読み取りプリセット・エンハンサーを記録から取る。説明プロンプトは今の `photo.txt` を使う (読み直さない)。

## 5. 設定

`%APPDATA%\ImageMimicArt\` に、ui-standard 15 章どおり設定 1 つにつき小さなテキストファイル 1 つで置く。共有するもの (接続先・ワークフロー・ベースプロンプト・`enhancer_presets.json`・`reader_presets.json`・`llm_url.txt`・`reader_model.txt`・`enhance_model.txt`・`reader_max_side.txt`) は `%APPDATA%\GenCommon\` に置く (generation-standard 8・11 章)。下の表はアプリごとのもの。

| ファイル | 内容 |
|---|---|
| (generation-standard 8 章の「アプリごと」のもの) | 使用中の番号・セット・前回の値・記録・ジョブ |
| `output_folder.txt` | 出力フォルダ (PC ごとのものなので、エクスポートには含めない) |
| `enhancer_generate.txt` / `enhance_preset.txt` | 生成の画面で前回選んだエンハンサー / 右の枠で選んでいるもの |
| `reader_generate.txt` / `reader_preset.txt` / `reader_reread.txt` | 生成の画面で前回選んだ読み取りプリセット / 右の枠で選んでいるもの / 「読み直す」のチェック |
| `lastfolder.txt` / `sort.txt` / `window.txt` / `splitter.txt` | 前回のフォルダ / 並び順 / 窓の位置と大きさ / ツリー・中央・右の枠の幅 |
| `grid_window.txt` / `grid_tile.txt` | グリッド一覧の位置と大きさ / タイルの大きさ |

## 6. 決めたこと (細部)

- **縦横比・大きさ**: アプリでは触らない。ワークフローに書かれたまま生成する。
- **初めて起動したときの引き継ぎ**: generation-standard 11 章「初めて共有するとき」に置き換えた (PromptWordCrafter の設定を写す仕組みはやめる)。
- **LLM の設定**: 読み取り用モデルも初めはエンハンサー用と同じ名前を入れるが、ビジョン非対応のモデルなら画像を受け付けないので、そのときは「読み取りの設定」でビジョン対応のモデルに替えるよう案内する。
- **読み取りのきっかけ**: 「読み取る」ボタン (Ctrl+R) と、まとめて生成のジョブの中だけ。画像を選んだだけでは読み取らない。
- **読み取りプリセットの初期値**: アプリ側で例を 2 つ (詳しい自然文の説明 / タグ) 用意する。使いながら書き換える。
